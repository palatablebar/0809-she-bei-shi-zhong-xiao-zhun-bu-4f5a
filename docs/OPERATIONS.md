# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。
3. 修复来源文件，重新上传并执行。历史批次保留供复核。
4. 运行对账逐组核对输入、采信、隔离与被拒记录。无问题组可单独签发并固定证据；问题组只挡住自身并列出记录键。存在无法归属设备组的隔离行时，其余组不能视为已完整核对，需先澄清来源。
5. 整批对账无差异且无坏行时可签发整批。对仍有差异的版本可填写暂缓意见。
6. 导出复核证据并保存于交接记录。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次。恢复时使用原 Docker Compose 数据卷。
